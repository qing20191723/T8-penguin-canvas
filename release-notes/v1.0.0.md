# 清尘无限画布 v1.0.0

首个面向 Windows 10/11 x64 的 Atlas 桌面发行版。

## 核心能力

- 本地无限画布、项目、运行记录和素材管理。
- Atlas Cloud 动态模型目录与可搜索模型选择器。
- 图片、视频、LLM、TTS、音乐和 ASR 节点。
- Seedream 5 Pro、Nano Banana Pro、GPT Image 2、Seedance 2.0、Wan 2.7、Wan 2.7 Spicy、Kimi K3、Seed Audio 等 Atlas 模型链路。
- Atlas API Key 通过 Windows DPAPI / Electron `safeStorage` 加密保存，不写入仓库或前端包。
- 自动更新仅连接 `qing20191723/T8-penguin-canvas` 的 GitHub Releases。

## 安装

1. 下载 `Qingchen-AtlasCanvas-Setup-1.0.0.exe`。
2. 同时下载 `.sha256` 文件并核对安装包 SHA-256。
3. 运行安装程序，选择安装目录。
4. 首次启动后，在设置中填写自己的 Atlas Cloud API Key 并测试连接。

## Windows 提示

本版本未购买代码签名证书。Windows SmartScreen 可能显示“未知发布者”。请确认安装包来自本仓库的正式 `v1.0.0` Release，并核对 SHA-256 后，通过“更多信息”继续安装。

## 数据与升级

画布、项目、素材、运行记录和加密密钥保存在 Electron `userData`。默认覆盖安装和卸载不会主动删除该目录。
